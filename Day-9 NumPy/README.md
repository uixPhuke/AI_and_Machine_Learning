- 🔄 FFT Support
- 🧠 Machine Learning Foundation

pip install numpy

## 🚀 Quick Start

```python
import numpy as np

arr = np.array([1, 2, 3, 4, 5])

print(arr.mean())
print(arr.sum())
```

---

## 📊 Array Creation

```python
np.zeros((3,3))
np.ones((3,3))
np.arange(0,10)
np.linspace(0,1,5)
```

---

## 🔢 Mathematical Operations

```python
a = np.array([1,2,3])
b = np.array([4,5,6])

print(a+b)
print(a*b)
print(np.sqrt(a))
```

---

## 📈 Linear Algebra

```python
matrix = np.array([[1,2],[3,4]])

np.linalg.det(matrix)
np.linalg.inv(matrix)
```

---

## 📊 Statistics

```python
data = np.array([10,20,30,40,50])

np.mean(data)
np.median(data)
np.std(data)
```

---

## 🎲 Random Numbers

```python
np.random.seed(42)
np.random.rand(5)
np.random.randint(1,100,5)
```
